F4Enix — an introduction06a · migjorn

New in F4Enix v1.0.0+

A parser built to edit, not just read.

Earlier versions parsed MCNP inputs with numjuggler, a reliable work-horse well known in the community.

But numjuggler was designed to parse, not to manipulate, which made editing in F4Enix cumbersome. Its maintenance has also dropped almost to zero.

So we wrote migjorn, an in-house parser for one of the toolkit's most important jobs.

Parsing the E-Lite model

F4Enix — an introduction08 · Hands on

Hands on

Five commands, then let's go.

  1. Open a Miniforge, Anaconda or command prompt with Python and Git available. Then clone the training:

    git clone https://github.com/Fusion4Energy/f4enix_training

  2. Create an environment

    conda create -n f4enix_workshop python=3.12

  3. Activate it

    conda activate f4enix_workshop

  4. Install F4Enix and the Jupyter kernel

    pip install f4enix ipykernel

  5. Check everything works; you should see ALL CHECKS PASSED

    python check_setup.py
